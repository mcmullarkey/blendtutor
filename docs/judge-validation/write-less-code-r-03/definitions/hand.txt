Pass only if a learner could act on it right away: it says what to change, look at, or try next in this code. Fail if it only says the answer is wrong, only encourages, or stays so general it would fit any submission. Handing over a complete working solution does not count as a next step. Stating the corrected expression or the exact edit (for example, telling the learner to use `6 - x`) also does not count, even when the exercise text mentions it: that gives the answer instead of the thinking that leads to it. Pass only feedback that points the learner at what to check or reason about, so they can work out the fix themselves.
