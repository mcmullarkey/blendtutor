# Vision — BlendTutor

BlendTutor is a hands-on, narrative-first learning platform: every lesson is a runnable artifact. The mdBook guide walks a learner from "hello" to "the whole game" through real tooling (Quarto, R, Rust), with reproducible example sites, live eval evidence, and an API reference — so finishing a chapter means having run it yourself.
