Pass only if feedback gives an immediate, exercise-specific next step—what to inspect, change, or try in this submission—without revealing the substantive solution. Fail if it merely marks work wrong, only encourages, or is generic enough to fit any submission. Precise diagnosis, including location and cause, naming required identifiers, and restating task-specified behavior or examples, including their expected outputs, are not leakage merely because they are exact. Leakage includes disclosing a complete solution, corrected solution code, an exact change that implements the answer, a key solution expression or value, or an expected output the learner must derive. A key solution expression remains leakage even when quoted from or attributed to the prompt. Leakage invalidates otherwise specific feedback; testing or rerun instructions do not cure it.
